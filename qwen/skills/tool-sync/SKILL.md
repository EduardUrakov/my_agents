# Tool Sync

## Когда использовать
- Для синхронизации с GitHub, Linear, Notion.
- Экспорт документации в Obsidian.
- Синхронизация задач и артефактов.
- Поддержание актуальности в разных инструментах.

## Процесс
1. **Настройка**: Подключить внешние инструменты.
2. **Чтение**: Загрузить данные из источника.
3. **Синхронизация**: Обновить целевые системы.
4. **Верификация**: Проверить результаты.

## Инструменты
- **GitHub**: Issues, PR, Wiki.
- **Linear**: Задачи и спринты.
- **Notion**: Документация и базы знаний.
- **Obsidian**: Заметки и граф знаний.

## Правила
- Read before write: сначала читать, потом писать.
- Reconcile, never clobber: согласовывать, не перезаписывать.
- Explicit-invocation: только по явным запросам.
