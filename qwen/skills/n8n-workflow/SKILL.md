# N8N Workflow

## Когда использовать
- Создание новых автоматизаций в n8n.
- Оптимизация существующих воркфлоу.
- Интеграция с внешними API.

## Процесс
1. **Анализ**: Определить триггеры, узлы, конечные точки.
2. **Проектирование**: Схема пайплайна и обработки данных.
3. **Реализация**: JSON-код воркфлоу с Code Nodes.
4. **Тестирование**: Проверка всех сценариев и ошибок.

## Правила
- Формат вывода: `return [{ json: { ... } }];`
- Обработка ошибок: `try/catch` для всех внешних вызовов.
- Безопасность: Только переменные окружения.
