# Cross Review

## Когда использовать
- Перед важным деплоем.
- Для независимой проверки критического кода.
- При сомнениях в качестве решений.
- Для верификации между разными моделями.

## Процесс
1. **Подготовка**: Подготовить код для ревью.
2. **Ревью**: Запустить ревью через другую модель/агента.
3. **Сравнение**: Сравнить результаты.
4. **Решение**: Принять решение на основе обоих ревью.

## Правила
- Использовать независимую модель для ревью.
- Не допускать компромиссов в безопасности.
- Фиксировать результаты в `.itd-memory/`.
- Принимать только согласованные решения.

## Результат
- Статус: `PASSED` / `PASSED_WITH_WARNINGS` / `BLOCKED`.
- Сравнение мнений моделей.
- Итоговые рекомендации.
