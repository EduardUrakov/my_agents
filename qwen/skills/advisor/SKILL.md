# Advisor

## Когда использовать
- Для анализа без изменения кода.
- При принятии архитектурных решений.
- Для multi-perspective evaluation.
- При сомнениях в правильности подхода.

## Процесс
1. **Анализ**: Изучить проблему с разных сторон.
2. **Перспективы**: Бизнес, техническая, пользовательская.
3. **Рекомендации**: Предложить варианты решений.
4. **Риски**: Оценить риски каждого варианта.

## Перспективы
- **Business**: Влияние на бизнес и ROI.
- **Technical**: Технические последствия.
- **User**: Влияние на пользователей.
- **Risk**: Риски и mitigation.

## Результат
- Анализ проблемы.
- Варианты решений.
- Рекомендации.
- Оценка рисков.
