# Autopilot

## Когда использовать
- Для автоматизации полного цикла разработки.
- Когда проект хорошо определен.
- Для быстрых MVP.
- При наличии четких требований.

## Процесс
1. **Discover**: Исследование и анализ.
2. **Blueprint**: Планирование.
3. **Kickstart**: Инициализация.
4. **Review**: Автоматическое ревью.
5. **Test**: Генерация тестов.
6. **Deploy**: Деплой.

## Правила
- Минимальное вмешательство пользователя.
- Автоматическое ревью и тесты.
- Фиксация прогресса в `.itd-memory/`.
- Пауза при критических проблемах.

## Результат
- Готовый проект с документацией.
- Пройденные тесты.
- Деплой на выбранную платформу.
