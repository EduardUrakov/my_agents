# Dependency Audit

## Когда использовать
- Перед обновлением зависимостей.
- При обнаружении уязвимостей.
- Для оценки актуальности пакетов.
- Перед деплоем.

## Процесс
1. **Сканирование**: Проверить все зависимости.
2. **Уязвимости**: Найти известные CVE.
3. **Актуальность**: Проверить версии.
4. **Лицензии**: Проверить совместимость.
5. **Отчет**: Список рекомендаций.

## Чеклист
- [ ] Нет известных уязвимостей.
- [ ] Все зависимости актуальны.
- [ ] Лицензии совместимы.
- [ ] Нет заброшенных пакетов.
- [ ] Lockfile актуален.

## Инструменты
- **npm audit**: Для Node.js.
- **pip-audit**: Для Python.
- **Safety**: Для Python.
- **Dependabot**: Автоматические PR.
