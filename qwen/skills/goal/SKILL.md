# Goal Management

## Когда использовать
- Для многошаговых проектов.
- При работе над сложными задачами.
- Для отслеживания прогресса по целям.
- Перед началом новой сессии разработки.

## Процесс
1. **Определение цели**: Четко сформулировать цель.
2. **Декомпозиция**: Разбить на подзадачи.
3. **Приоритизация**: Определить порядок выполнения.
4. **Выполнение**: Работать над задачами по очереди.
5. **Отслеживание**: Обновлять статус и прогресс.

## Формат GOAL.json
```json
{
  "goal": "Краткое описание цели",
  "status": "active",
  "units": [
    {
      "id": "U-1",
      "task": "Описание задачи",
      "status": "pending",
      "verified": false
    }
  ]
}
```

## Правила
- WIP=1: Работать над одной задачей за раз.
- Evidence-gated: Каждая задача должна быть проверена.
- Верификация: Использовать `/test` и `/code-review`.
- Сохранение: Обновлять `.itd-memory/GOAL.json` после каждого шага.
