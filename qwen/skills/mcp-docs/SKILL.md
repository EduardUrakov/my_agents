# MCP Docs

## Когда использовать
- Перед добавлением новой зависимости.
- Для поиска примеров использования.
- При интеграции с SDK.
- Для актуальной документации.

## Процесс
1. **Поиск**: Найти документацию через MCP.
2. **Вопрос**: Сформулировать узкий вопрос.
3. **Ответ**: Получить ответ с источником.
4. **Фиксация**: Записать источник и решение.

## Правила
- Только read-only доступ.
- Фиксировать источники.
- Использовать для narrow questions.
- Не заменять официальную документацию.

## Интеграции
- **Context7**: MCP провайдер документации.
- **Official Docs**: Официальная документация.
- **Examples**: Примеры использования.
