# Browser Check

## Когда использовать
- После изменений во фронтенде.
- Перед деплоем.
- Для проверки визуальных регрессий.
- Тестирования пользовательских сценариев.

## Процесс
1. **Настройка**: Запустить локальный сервер.
2. **Запуск**: Открыть в браузере.
3. **Проверка**: Верстка, адаптив, интерактивность.
4. **Скриншоты**: Зафиксировать состояние.
5. **Отчет**: Список найденных проблем.

## Инструменты
- **Playwright**: Автоматизация браузера.
- **Puppeteer**: Альтернатива для Chrome.
- **Cypress**: E2E тестирование.

## Чеклист проверки
- [ ] Верстка не сломана.
- [ ] Адаптив работает (320px, 768px, 1280px).
- [ ] Навигация работает.
- [ ] Формы валидируются.
- [ ] Анимации работают.
- [ ] Доступность (keyboard, aria).
- [ ] Нет ошибок в консоли.

## Отчет
- Статус: `PASSED` / `PASSED_WITH_WARNINGS` / `BLOCKED`.
- Скриншоты состояний.
- Список проблем с приоритетами.
