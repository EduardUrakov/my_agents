# Obsidian Export

## Когда использовать
- Для экспорта документации в Obsidian.
- Создание knowledge graph.
- Сохранение планирования и памяти.
- Формирование заметок и графов.

## Процесс
1. **Анализ**: Определить данные для экспорта.
2. **Форматирование**: Подготовить в формате Obsidian.
3. **Экспорт**: Записать в `.itd-integrations/obsidian/`.
4. **Верификация**: Проверить импортируемость.

## Формат
- Markdown с YAML frontmatter.
- Ссылки через `[[wiki links]]`.
- Теги для категоризации.
- Даты и метаданные.

## Результат
- Готовые файлы для Obsidian.
- Knowledge graph в формате Obsidian.
- Связанные заметки и графы.
