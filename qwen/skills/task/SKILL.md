# Task Router

## Когда использовать
- Для работы с существующим кодом.
- Когда нужно определить тип задачи.
- Для маршрутизации к нужному скиллу.

## Маршрутизация
- **Баг** → `/bugfix`
- **Рефакторинг** → `/refactor`
- **Документация** → `/doc`
- **Тесты** → `/test`
- **Производительность** → `/perf`
- **Безопасность** → `/security-audit`
- **Миграция** → `/migrate`
- **Деплой** → `/deploy`

## Процесс
1. **Анализ**: Определить тип задачи.
2. **Маршрут**: Выбрать нужный скилл.
3. **Выполнение**: Делегировать субагенту.
4. **Проверка**: Убедиться в результате.

## Правила
- Всегда уточнять задачу перед выполнением.
- Использовать соответствующий скилл.
- Фиксировать результат в `.itd-memory/`.
