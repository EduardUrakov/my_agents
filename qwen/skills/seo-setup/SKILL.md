# SEO Setup

## Когда использовать
- При создании нового сайта.
- Для улучшения SEO текущего проекта.
- Перед запуском marketing campaigns.
- Для технической оптимизации.

## Процесс
1. **Анализ**: Проверить текущее SEO.
2. **Meta**: Настроить meta теги.
3. **Schema**: Добавить Schema.org разметку.
4. **Sitemaps**: Создать sitemap.xml.
5. **CWV**: Оптимизировать Core Web Vitals.
6. **Local**: Настроить локальное SEO.

## Чеклист
- [ ] Title и Description оптимизированы.
- [ ] Open Graph теги есть.
- [ ] Schema.org разметка добавлена.
- [ ] Sitemap.xml создан.
- [ ] robots.txt настроен.
- [ ] Core Web Vitals в норме.
- [ ] Canonical URLs указаны.

## Инструменты
- **Google Search Console**: Мониторинг.
- **PageSpeed Insights**: Анализ скорости.
- **Screaming Frog**: Аудит сайта.
