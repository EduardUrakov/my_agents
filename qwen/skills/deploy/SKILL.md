# Deploy

## Когда использовать
- Деплой проекта на продакшен.
- Настройка CI/CD пайплайнов.
- Миграция на новый сервер.

## Процесс
1. **Анализ**: Определить целевую платформу (VPS, Vercel, Railway и т.д.).
2. **Подготовка**: Конфигурация окружения, переменные, зависимости.
3. **Деплой**: Запуск на сервере или платформе.
4. **Верификация**: Проверка health-check, логов, основного функционала.

## Правила
- Всегда делать бэкап перед деплоем.
- Проверять health-check после деплоя.
- Документировать изменения в README.
