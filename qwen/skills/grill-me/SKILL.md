# Grill Me

## Когда использовать
- Перед `/review` для дополнительной проверки.
- Для выявления скрытых рисков.
- При сомнении в правильности решений.
- Для валидации архитектуры.

## Процесс
1. **Вопросы**: Задавать по одному вопросу за раз.
2. **Ответы**: Получать ответы от пользователя.
3. **Анализ**: Выявлять слабые места.
4. **Рекомендации**: Предлагать улучшения.

## Типы вопросов
- **Assumptions**: Какие предположения сделаны?
- **Risks**: Какие риски есть?
- **Dependencies**: Какие зависимости?
- **Fallbacks**: Что делать при ошибке?
- **Scalability**: Как масштабировать?

## Результат
- Список выявленных рисков.
- Рекомендации по улучшению.
- Подтверждение готовности к `/review`.
