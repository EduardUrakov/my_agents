# Kickstart

## Когда использовать
- Создание нового проекта с нуля.
- Генерация структуры, документации и базового кода.

## Процесс
1. **Идея**: Уточнить требования, стек, ЦА.
2. **План**: Сформировать структуру проекта и этапы разработки.
3. **Скелет**: Создать директории, конфиги, базовые файлы.
4. **Документация**: README, PRD, архитектура.
5. **Старт**: Базовая реализация ключевого функционала.

## Выходные данные
- Готовая структура проекта.
- Документация.
- Базовый рабочий код.
