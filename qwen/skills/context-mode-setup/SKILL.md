# Context Mode Setup

## Когда использовать
- При начале новой сессии.
- Для настройки ограничений и контекста.
- При смене приоритетов или фокуса.
- Для адаптации под текущие условия.

## Процесс
1. **Анализ**: Определить текущий контекст.
2. **Настройка**: Выбрать режим работы.
3. **Ограничения**: Установить границы.
4. **Фиксация**: Записать в `.itd-memory/`.

## Режимы
- **Development**: Полная разработка.
- **Review**: Только ревью и аудит.
- **Documentation**: Только документация.
- **Debugging**: Только отладка.
- **Research**: Только исследования.

## Ограничения
- **Time**: Ограничения по времени.
- **Budget**: Ограничения по бюджету.
- **Stack**: Ограничения по стеку.
- **Scope**: Ограничения по области.
