# Guide

## Когда использовать
- Когда есть документация, но нужна реализация.
- Для пошагового руководства по коду.
- Onboarding новых разработчиков.
- Передача проекта другому агенту.

## Процесс
1. **Анализ**: Изучить существующую документацию.
2. **Декомпозиция**: Разбить на шаги.
3. **Инструкции**: Написать пошаговые инструкции.
4. **Примеры**: Добавить примеры кода.
5. **Проверка**: Убедиться, что инструкции понятны.

## Формат
- **Шаг N**: Описание задачи.
- **Цель**: Что должно быть сделано.
- **Файлы**: Какие файлы изменить/создать.
- **Код**: Примеры изменений.
- **Проверка**: Как проверить результат.

## Результат
- Пошаговое руководство по реализации.
- Примеры кода для каждого шага.
- Критерии успешного выполнения.
