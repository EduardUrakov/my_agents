# Product Discovery

## Когда использовать
- Перед началом нового проекта.
- Для анализа рынка и конкурентов.
- Определения целевой аудитории.
- Приоритизации функционала.

## Процесс
1. **TAM/SAM/SOM**: Оценка рынка.
2. **Конкуренты**: Анализ решений.
3. **Персоны**: Определение ЦА.
4. **Функционал**: Приоритизация (MoSCoW, RICE).
5. **DISCOVERY.md**: Формирование отчета.

## Метрики
- **TAM**: Total Addressable Market.
- **SAM**: Serviceable Available Market.
- **SOM**: Serviceable Obtainable Market.
- **RICE**: Reach, Impact, Confidence, Effort.
- **MoSCoW**: Must have, Should have, Could have, Won't have.

## Результат
- **DISCOVERY.md**: Отчет с анализом рынка.
- **Персоны**: Портреты целевой аудитории.
- **Приоритеты**: Список функций по важности.
- **Конкуренты**: Сравнительная таблица.
