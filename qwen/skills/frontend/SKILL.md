# Frontend Design

## Когда использовать
- Создание UI-компонентов, страниц или фронтенд-приложений.
- Редизайн существующих интерфейсов.
- Конвертация макетов в рабочий код.

## Правила проекта
- **Верстка**: Только относительные единицы (`rem`, `em`, `vh/vw`, `flex`, `grid`).
- **Семантика**: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- **Стиль**: БЭМ для CSS.
- **Язык**: Vanilla JS, HTML5, CSS3/SCSS. Без тяжелых фреймворков для MVP.

## Процесс работы
1. **Анализ**: Уточнить цель, целевую аудиторию, constraints.
2. **Концепция**: Предложить эстетическое направление перед кодом.
3. **Реализация**: Написать код с уникальными решениями.
4. **Валидация**: Проверить адаптивность (375px, 768px, 1280px) и семантику.

## Критерии готовности
- [ ] Код адаптивен и работает на всех разрешениях.
- [ ] Используется семантическая разметка.
- [ ] CSS следует БЭМ.
- [ ] Нет жестких пикселей в макете.
- [ ] Доступность (WCAG AA).
