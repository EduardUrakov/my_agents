# Blueprint

## Когда использовать
- Для планирования проекта перед разработкой.
- Когда нужна архитектура и документация.
- Для оценки сроков и ресурсов.
- Перед запуском `/kickstart`.

## Процесс
1. **Анализ**: Изучить требования и constraints.
2. **Архитектура**: Спроектировать стек и структуру.
3. **План**: Создать поэтапный план разработки.
4. **Документация**: Сгенерировать 6 ключевых документов.
5. **Review**: Проверить план через `/code-review`.

## Документы
1. **STRATEGIC_PLAN.md**: Стратегия, конкуренты, бюджет.
2. **PRD.md**: Пользовательские истории, требования.
3. **PROJECT_ARCHITECTURE.md**: Стек, БД, API.
4. **IMPLEMENTATION_PLAN.md**: Пошаговый план.
5. **README.md**: Быстрый старт.
6. **CLAUDE.md**: Правила проекта.

## Результат
- Полный комплект документации.
- Оценка сроков и ресурсов.
- Готовность к `/kickstart`.
