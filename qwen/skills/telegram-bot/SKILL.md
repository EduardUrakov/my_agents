# Telegram Bot

## Когда использовать
- Создание нового Telegram-бота.
- Разработка многошаговых сценариев.
- Интеграция бота с внешними системами.

## Процесс
1. **Проектирование**: Схема команд, состояний, клавиатур.
2. **Реализация**: Код бота с поддержкой состояний.
3. **Интеграция**: Подключение к n8n, БД, API.
4. **Тестирование**: Проверка всех путей пользователя.

## Правила
- Формат: `MarkdownV2` с экранированием.
- Состояния: Явная обработка переходов.
- Безопасность: Валидация payload.
