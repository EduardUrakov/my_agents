# Market Scan

## Когда использовать
- Для валидации идеи продукта.
- Перед запуском нового проекта.
- Для отслеживания конкурентов.
- Для определения трендов.

## Процесс
1. **Поиск**: Найти последние новости и тренды.
2. **Анализ**: Оценить значимость сигналов.
3. **Конкуренты**: Проверить их действия.
4. **MARKET_BRIEF.md**: Сформировать отчет.

## Метрики
- **Trends**: Тренды в индустрии.
- **Competitors**: Действия конкурентов.
- **Users**: Мнения и потребности пользователей.
- **Tech**: Новые технологии и инструменты.

## Результат
- **MARKET_BRIEF.md**: Отчет с анализом.
- **Recommendations**: Рекомендации по стратегии.
- **Risks**: Выявленные риски.
